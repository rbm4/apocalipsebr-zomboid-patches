AVISO IMPORTANTE

Este patch vai modificar a instalação local do Project Zomboid.
Ao continuar, o script pode baixar automaticamente um JDK Java da Azul Zulu e
compilar classes Java para dentro da pasta do Project Zomboid encontrada pela
Steam.

É de extrema importância que sua instalação esteja livre de outros "mods java"
do Project Zomboid. A utilização de 2 ou mais mods java juntos não possuem nenhuma
garantia de funcionar juntas, caso o seu Project Zomboid não inicie, é um indicativo
de que o patch está quebrado

Qualquer atualização do Project Zomboid pode quebrar este patch, sobrescrever
arquivos alterados ou fazer o jogo parar de abrir até que o patch seja removido
ou aplicado novamente em uma versão compatível.

Como desinstalar:

1. Feche o Project Zomboid.
2. Execute desinstalador.bat na raiz deste repositório.
3. Se preferir usar PowerShell diretamente, execute:
   powershell -ExecutionPolicy Bypass -File .\patch-client.ps1 -Revert
4. Se a Steam atualizar o jogo, use "Verificar integridade dos arquivos" na
   Steam para restaurar a instalação original.

Não há garantia de uma gameplay idêntica à original, alguns elementos do 
jogo podem quebrar, utilize a aba "Issues" do repositório abaixo para reportar bugs.
